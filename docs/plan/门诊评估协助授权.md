# 门诊评估协助授权

- [X] 1. 患者同意门诊评估后，按本次就诊登记协助人、关系、可协助范围与本人明确确认；同一就诊只保留一条生效授权。
- [X] 2. 服务端固定可协助范围并拒绝认知、谵妄、现场操作和他评项目，联系方式只落库末四位掩码。
- [X] 3. 患者端可授权、替换和撤销；职工任务详情只读展示授权状态与范围；门诊结束后的写入被拒绝。

本分支接在 `feat/outpatient-assessment-consent` 之后，只做“授权与来源边界”这一层，不改变现有
问卷提交路径。对应《项目构想总需求.md》FR01 的角色区分与 AC02 的来源、授权、操作者要求。

## 数据与接口

新增 `patient_assistance_authorization` 表：`patient_id`、`encounter_id`、可选 `consent_record_id`、
`helper_name`、`helper_relation`、`helper_contact_masked`、`assist_scope`（JSONB 编码列表）、
`status`、`authorized_at`、`revoked_at`、`revoke_reason`、`recorded_by`。授权按就诊归属，
历史记录只撤销不覆盖，便于追溯谁在什么时间被允许协助什么范围。

授权前必须已有本次任务的“同意”决定，否则返回 403；门诊结束后写入返回 401。协助人关系和范围
使用固定枚举，未知取值由请求校验拒绝，不在服务端保留自由文本。

## 范围口径

可协助：病史与主诉、用药与过敏、照护安排、B.1、B.2、B.9、B.4 至 B.7、B.11、B.13、B.18 与 B.19，
以及 B.14（本人自评，他人仅可代为读出问题）。

不可代答：B.8 简易智力评估与画钟、B.21 谵妄评估、B.3 简易体能状况现场测试，以及 B.12、B.15、B.16、
B.17、B.20 等需要专业观察或现场操作的项目。该清单同时通过接口返回，供页面直接展示，不靠前端自行约定。

## 未覆盖与后续

- 协助人代为作答时的提交来源尚未写入 `assessment_submission.submitter_type` 与
  `assessment_answer.value_source`，下一分支在问卷提交入口接入并在报告数据限制中体现。
- 手写授权书、协助人身份核验和家属代签仍按机构流程另行确认；本表只记录电子授权事实。
- 与 `consent_authorization`（家属代签同意书）保持分工：本表管采集协助范围，代签授权仍在知情同意域。
