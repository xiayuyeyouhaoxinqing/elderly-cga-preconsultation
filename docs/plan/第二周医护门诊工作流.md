# 第二周医护门诊工作流

- [X] 1. 补齐职工端门诊操作
  - [X] 1.1 在患者管理中按门诊状态筛选，为已有患者登记和结束门诊评估。
  - [X] 1.2 创建任务时选定一次具体就诊。门诊评估由患者本人填写已发布量表。
- [X] 2. 验证门诊工作流
  - [X] 2.1 在独立 PostgreSQL 和 Redis 环境验证职工权限、并发登记、发布任务与关闭会话。
  - [X] 2.2 在桌面职工端和 390 px 患者端验证登记、发布、查看任务、结束门诊及旧链接失效。

## 测试入口

职工登录后进入「患者管理」，打开已建档患者的详情，填写门诊科室并登记。选择「创建门诊评估任务」，勾选已发布的量表并发布。患者端选择「门诊评估」，填入身份证号与登记手机号后可查看本次任务。

重新打开职工端患者详情并确认结束门诊评估。患者端下次刷新或请求任务时返回身份核验页，原门诊建任务链接会提示就诊已无法创建任务。
