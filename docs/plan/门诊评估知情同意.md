# 门诊评估知情同意

- [X] 1. 按机构配置给新门诊任务绑定指定已发布文书版本。沿用已有知情同意表。
- [X] 2. 患者核验后查看原文，明确选择同意或拒绝。服务端限制本次就诊并控制问卷读写。

这次使用患者身份核验后的电子确认记录。机构在测试或实际启用前提供已审核文书。手写签名与家属代办另行对齐机构流程。

## 配置与测试

将机构确认的文书作为 `outpatient_assessment` 类型保存。文书主档为启用状态，选用的版本须已发布、在生效期内并含完整原文。设置 `APP_SECURITY__OUTPATIENT_CONSENT_DOCUMENT_CODE` 为该文书编码。已有门诊任务沿用创建时的绑定情况。关闭配置仅停止为新任务绑定文书。使用数据库已有表，本分支无需新增迁移。

在隔离环境创建任务后，患者核验进入任务详情。待确认和拒绝时，患者的问卷读取、草稿和提交均被服务端拒绝。确认同意后打开问卷。再次提交同一决定时保留原决定时间。拒绝后任务暂停，责任职工可查看状态。

真实 PostgreSQL 和 Redis 的后端回归共 278 项通过。使用 390 px 患者端和桌面职工端验证同意后打开问卷、拒绝后刷新仍显示暂停，以及职工读取决定。
