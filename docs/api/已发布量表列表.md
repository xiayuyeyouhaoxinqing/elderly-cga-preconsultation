# 已发布量表列表查询增量契约

GET /api/scales，沿用医护Cookie鉴权及{code,message,data}响应。未登录或只有患者Cookie不能替代医护身份。

可选keyword：最多50个原始字符，去首尾空格后按名称不区分大小写文字子串匹配；%和_按字面转义，不成为通配符。缺省、空串和空白保持旧行为。超长参数由FastAPI返回422。无匹配返回成功空列表，不返回404。

data字段仍为AssessmentScaleDto数组，字段不变：id、scale_code、scale_name、scale_type、question_count、version_code、description。成功code仍为字符串OK，无新增分页或total。

保留当前生效、已发布及未删除过滤、每表当前版本选择和id排序。前端通过listScales(signal?, filters?)访问，原单参数调用不变。版本/题目数从实际API映射；旧Mock题库未携带的元数据展示“未提供”，不编造临床版本。

代码入口：backend/app/api/scales.py、services/scale_service.py、schemas/scale.py；机器契约查看运行中的/openapi.json。前端入口src/lib/repositories/types.ts、apiRepository.ts、mockRepository.ts和src/app/nurse/scales/page.tsx。
